## 2. What is left / broken (found during audit)

### Correctness bugs (visible to visitors)
1. **Stale "upcoming" event.** `deriveEventStatus()` trusts the stored `status` field, so *Global Azure France 2026* (18 Apr 2026) is still shown as **"Prochain événement / À venir"** on the home page and events list seven months later. Status must be computed from dates at build time (only `cancelled` should be stored).
2. **Broken organizer photos.** About page references `/organizers/*.jpg` but `public/organizers/` does not exist → 5 × 404 and alt text spilling over the card.
3. **Dangling speaker references.** Events reference ~40 `speakerSlugs` but only 2 speaker files exist — and those two (`marie-dupont`, `jean-martin`) are **fictional fixtures**. Speaker pages for real speakers are never generated. Slug drift too (`igor-leontiev` vs `ihor-leontiev`).
4. **Sample / fake content still published.** `azure-meetup-sample.json` (fake May-2025 event with fake speakers), `azugfr-news-sample.json` (fake LinkedIn URL), `intro-azure-openai-slides.json` (fake Speaker Deck URL), `microsoft-france.json` sponsor rendered as plain text.
5. **Global Azure France page is incomplete.** Editions list shows 2026, 2022, 2022, 2019 — the 2023, 2024 and 2025 editions (which exist as events) are missing; past editions show an **"S'inscrire"** (register) button.
6. **Footer dead-ends.** "Code de conduite", "Contact", "Sponsors" all point to `/about`; "À venir"/"Passés" both point to the same list without anchors.
7. **No talk-level data.** Events only have a free-text description; talks (title, speakers, slides, video) are not modelled, so "what was presented" is not browsable — the core value of a user-group site.
8. **Test config bug.** `vitest run` picks up `tests/browser/smoke.spec.ts` (Playwright) → 1 failed suite. Browser smoke tests are not run in CI at all.

### Not done from the original backlog
- Meetup / RSS secrets + scheduled sync workflow (`MEETUP_KEY`, `RSS_BRIDGE_URL`).
- Legacy `img/gab/*` assets from `master` not migrated.
- Cutover not executed (`master` is still the live branch; `azugfr.github.io` currently returns 404).
- Code of conduct, contact and sponsors/"host us" content do not exist.

## 3. Enhancement proposal

### 3.1 Design
| # | Proposal | Why |
|---|---|---|
| D1 | **Hero with proof, not repetition.** Replace the duplicated "Azure User Group France" lines with a value statement + live stats (events since 2014, talks, speakers, members) and the next event inline. | Current hero says the same thing twice and gives no reason to join. |
| D2 | **Honest "next event" block.** When nothing is scheduled, show "Next meetup coming soon — follow us on Meetup / propose a talk" instead of a stale event. | Fixes bug #1 from a UX angle. |
| D3 | **"Latest talks" strip on home** (cards: talk title, speaker avatar(s), event, date). | Puts community content first. |
| D4 | **Event detail = agenda.** Timeline of talks with speakers, abstract, slides/video links; venue block with map link; partner/host logo. | The detail page today is a paragraph + button. |
| D5 | **Organizer cards with bios** — larger photo (initials fallback, no broken images), award badges, short bio, social icons. | Humanises the board; fixes broken images. |
| D6 | **Partners/hosts wall** built from event hosts (Onepoint, Devoteam, Société Générale, ESGI, Avanade, Meritis, Lokad, Nutanix, L'Atelier…) with "Host a meetup" CTA. | Today one grey text label; hosts are the community's real sponsors. |
| D7 | **Year filter / grouping on events archive** and an `Upcoming` / `Past` anchor nav. | 25+ cards in one grid is hard to scan. |
| D8 | Accessibility polish: visible focus rings, `aria-current` on nav, image fallbacks, colour-contrast check on footer greys, `prefers-reduced-motion`. | WCAG 2.1 AA baseline. |
| D9 | Social/OG: per-page OG images (event title), JSON-LD `Event` + `Organization`, `sitemap.xml`, `robots.txt`. | Discoverability of events on Google/LinkedIn. |
