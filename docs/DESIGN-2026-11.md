# AZUG FR visual identity (Nov 2026)

Approved direction for the `nextgen` site. It replaces the earlier "Azure blue, white cards, gray-50 bands"
look and the Penpot file as the visual reference (`requirements.md` §3 and `design.md` §8 point here now).

## Subject, audience, job

- **Subject:** AZUG FR, the volunteer-run Azure user group in France since 2014. Evening meetups (mostly at
  Microsoft France, Issy-les-Moulineaux), talks by practitioners, and the yearly Global Azure France.
- **Audience:** French-speaking cloud and dev practitioners; would-be speakers; venue hosts and sponsors.
- **Primary job:** get people to the next evening, and show the community is alive through its talks.

## Idea: a timetable of talks

The most characteristic thing the group has is its programme: who presented what, when. The home hero is a
list of the latest real talk titles, set large. Events read as an evening timetable. Everything else stays
quiet so that this is the one memorable thing.

## Colour

Taken from the AZUG FR logo (cloud, navy wordmark, tricolore). Defined once as CSS variables in
`src/styles/global.css` and exposed to Tailwind as named colours; no hex values in components.

| Token | Hex | Role |
|---|---|---|
| `ciel` | `#8FD3F4` | The logo's cloud. Large fields only: home hero, highlighted bands. Never text. |
| `ciel-soft` | `#D6EFFB` | Hover and selected-row tint, subtle fills. |
| `aube` | `#F3FAFE` | Pale sky behind the home hero. |
| `encre` | `#0B2545` | The logo's navy. Body text, headings, footer background. |
| `azur` | `#0078D4` | Buttons, links, active locale (R4j). White text on it passes AA. |
| `azur-deep` | `#005A9E` | Button hover, link hover, links on `ciel` (passes AA there). |
| `rouge` | `#E0362C` | Only marks "next": the date of the upcoming event and its marker. Never decoration. |
| `papier` | `#FFFFFF` | Page background. |
| `brume` | `#EEF4F8` | Alternating sections and quiet panels. |
| `trait` | `#C9D6E2` | Rules and borders. |
| `gris` | `#4A5B6E` | Secondary text (passes AA on `papier` and `brume`). |

Footer: `encre` background, white headings, links `#B9D3EA`, which passes AA on `encre`.

Contrast rules (measured, WCAG 2.1 AA):
- Text on `ciel` is `encre` only (9.4:1). Links on `ciel` are `encre` with an underline; `azur`, `azur-deep`
  and `rouge` never sit on `ciel`.
- `rouge` only at large size (24px+ bold, 4.4:1 on `papier`), e.g. the day number of the next event.
- Links on `brume` use `azur-deep`; `azur` text on `brume` is 4.1:1 and fails.
- `gris` passes on `papier` (7.0:1) and `brume` (6.3:1).

## Type

One family: **Archivo** (variable, weight 100–900, width 62–125), self-hosted through
`@fontsource-variable/archivo` (`wdth.css`), so there are no third-party font requests.

Personality comes from width, not from a second typeface:

| Role | Width | Weight | Size (mobile → desktop) | Line height |
|---|---|---|---|---|
| Wordmark h1 "AZUG FR" | 125 | 850 | 56 → 112px | 0.9 |
| Talk titles in the hero | 75 | 600 | 24 → 40px | 1.1 |
| Page h1 | 112 | 750 | 36 → 60px | 1.0 |
| h2 | 112 | 700 | 28 → 36px | 1.15 |
| h3 | 100 | 650 | 20 → 24px | 1.25 |
| Body | 100 | 400 | 18px | 1.55 |
| Small / meta | 100 | 450 | 15px | 1.45 |

- Scale: 15, 18, 20, 24, 28, 36, 40, 60, 112.
- Times and dates use `font-variant-numeric: tabular-nums`. No monospace anywhere.
- Body measure at most 70ch. Headings use `text-wrap: balance`.
- Sentence case everywhere. No all-caps labels, no tracked-out eyebrows above headings.
- No arrows appended to link text; no middle-dot meta strings (put meta in separate elements or columns).

## Layout

Left-aligned throughout, including page heroes. Container `max-w-6xl`, gutter 16px mobile, 32px desktop.
Lists replace card grids wherever the content is a list.

### Header
White, bottom rule in `trait`. Logo, nav links (active: `encre`, 2px `azur` underline), search, FR|EN
toggle (active `azur`, white, semibold, per R4j), "Rejoindre" button in `azur`. Mobile menu unchanged in
behaviour, restyled.

### Home

Revised after the first build: the saturated `ciel` field was too strong. The hero now sits on `aube`
(`#F3FAFE`), and the logo's cloud is drawn as a large outline (`HeroCloud.astro`: an outer `ciel` ring
left open at the lower left, an inner ring around a `ciel-soft` fill) cropped at the top-right, clear of the
text on large screens and faint behind it on small ones. Under the buttons a line says AZUG FR is the Paris
community of MTG France (Microsoft Tech Group France), linked to https://www.mtg-france.org/; the footer
and the About page repeat it. With no upcoming event, the "Prochaine soirée" block puts the text and buttons
on the left and the last evening, with its own date block, in a `brume` panel on the right.

The hero replaces the old "latest talks" card section. If there are no talks, the hero shows the h1,
tagline and CTAs only.

### Events index
Grouped by year (the year is a large h2; years are a real sequence). Each event is a row:
date column (day number large, month small, tabular) | title + venue | number of talks.
Upcoming events sit first with the date in `rouge`. Year filter links stay as plain text links.

### Event page
Date block as on the home page, then h1, venue and mode. Agenda as a timetable: time column (tabular,
`gris`) and talk column (title in h3 style, speakers below). Venue and registration in an aside panel
(`brume`, no shadow). The existing JSON-LD stays.

### Speakers
An A–Z roster: a letter heading per initial (a real sequence), names set at h3 size in 2–3 columns, with
talk count and headline beneath. A photo shows only when one exists; no initials circles in the list.
The speaker page keeps the large Avatar.

### About, Global Azure France, News, Resources, Search, 404
Same tokens and type. Page heroes become left-aligned h1 + one-line intro on `papier` (Global Azure France
may use the `ciel` field like home). The organizer board is a list of people with photo when present.
The 404 page gets the same tokens inline.

## Shape, depth, motion

- Radius: 6px on buttons and inputs, 10px on panels. Rows and lists have none.
- No drop shadows. Depth comes from `brume` panels and `trait` rules.
- Buttons: primary = `azur` fill, white text; secondary = 1.5px `encre` border on transparent.
- Motion: none on load. Only feedback to actions (menu open, row hover tint, focus). Respect
  `prefers-reduced-motion`.
- Focus: 2px `azur` outline, 2px offset; on `ciel` and `encre` backgrounds use a white/encre double ring
  so it stays visible.

## Sponsors

- New tier `honor` ("Sponsor d'honneur" / "Honorary sponsor"). Microsoft France moves from `host` to
  `honor` and is featured.
- Microsoft shows as a text wordmark until the official logo file is added to `public/sponsors/`.
  Do not pull Microsoft logos from the web.
